# Built Workers browser acceptance

This target reads the existing `dist/server/index.js` and `dist/client` output. It never invokes Next, deploys, reads `.env.local`, calls a provider, or reuses an existing database. Build once with `pnpm build:vinext`, then run `pnpm test:workers-browser`. `pnpm profile:workers-browser` runs the optional bounded local profile. Do not run a build while either target is reading the shared `dist` directory.

The harness uses the installed Wrangler Miniflare/workerd dependency and its v4-options converter, explicitly loads the built modules, discovers every SQL migration at runtime, and creates UUID-named transient D1/R2 bindings. Every browser test gets a new fixture containing only synthetic owner, staff, vendedor and catalogue rows. `dispose()` closes its own runtime and transient persistence. No live credentials, existing exports or production records are loaded.

The versioned wrapper under `scripts/fixtures` is test infrastructure, never a deployment entry point. It maps loopback transport to the public HTTPS origin compiled into the built artifact so canonical/indexability and recovery gates exercise their normal paths. The origin comes from public `wrangler.jsonc` settings; use `WORKERS_BROWSER_PUBLIC_ORIGIN` only when the build explicitly used that same override. The named public origin is never fetched. Static assets are read only inside `dist/client`, outgoing Worker fetches fail, browser service workers are disabled, and external browser requests are aborted. The profiling target fulfills only generated synthetic image bytes locally, without fetching public image URLs. Mail is an in-memory service stub. Failure and DB-outage switches exist only in the test wrapper.

The suite covers actual browser login/session, owner/staff product save and database readback, prepared image multipart upload through emitted client action references, import preview/confirmation, vendedor direct-action rejection, request size rejection, lost import acknowledgement/reload/resume with durable receipts and changed-file refusal. Recovery uses two contexts and checks fragment removal, password validation, generic unknown-account response, old-session rejection, new login, replay/expiry and failed-stub token deletion. The HTTP crawl checks every fixture sitemap entry, canonical 200/indexability, hidden exclusion, invalid category/search HTTP 404, filtered/search noindex, enquiry/hidden-price JSON-LD and fail-closed 503/no-store when the DB binding is missing. A separate fresh-runtime query-failure proxy verifies the existing static sitemap 200/no-store fallback with no product URLs.

Chrome is reused from its normal Windows installation when available; otherwise Playwright uses its installed Chromium. `PLAYWRIGHT_CHROMIUM_EXECUTABLE` can select an existing binary. No local download/install is performed. The standalone CI workflow installs Chromium on its ephemeral Linux runner, builds Vinext, runs only this suite, and retains the synthetic JSON report for seven days. It does not use a database/provider secret or deploy. CI execution is unverified until the workflow runs after publication.

Set `WORKERS_BROWSER_REPORT` for Playwright JSON and `WORKERS_BROWSER_OUTPUT` for scratch; traces, screenshots and video are disabled so reset fragments/session values are not exported. Set `WORKERS_BROWSER_PROFILE_REPORT` for the optional profile JSON. Local task evidence goes under `C:/Claude 1/reports/productos.new/2026-10-23/completion`; scratch under `C:/Claude 1/.task-temp/productos-completion-20261023`. The reports contain assertion outcomes and numeric metrics, not reset links, cookie values, email bodies or SQL values.

The profile uses fresh fixtures for four route labels × desktop/mobile × diagnostics off/on. It records browser landing TTFB/full delivery/DOMContentLoaded/LCP/CLS, image timing/encoded bytes/offscreen eager count, then a same-route first/repeat HTTP pair with headers/full-body duration/cache state/Server-Timing. The browser landing precedes this pair, so its DTO may be warm. Eligible catalogue pairs should exercise MISS/HIT; query search intentionally bypasses HTML cache. Home also measures a real category-link click and same-origin fetch timing separately from document navigation. Diagnostic mode buffers the complete response; do not compare it as if it were ordinary streaming. This tiny synthetic gallery and local network cannot establish real phone memory, image quality, visitor latency, or justify changing four-card image priorities. Keep current priorities until a matched real-device waterfall supports a change.
